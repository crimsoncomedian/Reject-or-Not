# Reject or Not

An interactive walkthrough of a hypothesis test for statistics students. Students write the null and alternative hypotheses from a short case, choose an alpha level, then watch a simulated sample land on a sampling distribution. They decide whether to reject H0 by looking at where the sample falls. The page shows the z-score and p-value as pictures, so no calculation is needed.

Live page: https://crimsoncomedian.github.io/Reject-or-Not/

One self-contained file (`index.html`), no build step and no running cost.
